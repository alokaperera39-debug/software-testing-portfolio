
# Software Testing Portfolio

## About This Portfolio

This repository showcases my manual software testing experience from the Aotearoa Is Home capstone project, developed during my Bachelor of Information Technology at WelTec/Whitireia.

## Project Overview

Aotearoa Is Home is a responsive web application designed to support international students and families settling in New Zealand.

## My Responsibilities

- Designed and executed manual test cases
- Prepared test plans and test conditions
- Performed functional, integration and system testing
- Identified and documented software defects
- Retested fixes and maintained screenshot evidence
- Collaborated with developers across four Agile sprints

## Testing Techniques

- Black-box testing
- Positive and negative testing
- Boundary value testing
- Functional testing
- Regression testing
